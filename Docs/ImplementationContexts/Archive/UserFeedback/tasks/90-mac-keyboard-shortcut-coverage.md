## 设计与库策略

- 遵循 Apple HIG：优先系统标准组合键与菜单发现性，避免占用系统/文本编辑常用组合；
  destructive 或依赖上下文的动作不得通过全局快捷键隐式执行。
- 遵循 SwiftUI skill：快捷键触发与视图生命周期解耦，命令只经稳定 action/command
  边界修改状态。
- 继续使用项目现有 `KeyboardShortcuts` 和本地 `MacKeyboardShortcuts` 适配包；不新增同类库。

## 覆盖裁决

| 分组 | 纳入可配置动作 | 默认 |
| --- | --- | --- |
| 创建 | 手动补录、选择任务开始、为所选任务添加子任务、新建任务分类 | 仅手动补录保留 `Shift-Command-M` |
| 计时 | 开始所选任务、停止所选任务、开始番茄钟 | 开始任务/番茄钟保留已有默认；停止默认不绑定 |
| 整理 | 归档所选任务、分类排序、生成 AI 任务计划 | 默认不绑定，避免低频或上下文动作抢占组合 |
| 导航 | 今日、收件箱、任务、专注、分析 | 保留 `Command-1` … `Command-5`，但允许修改或清空 |
| 数据 | 刷新数据 | 保留 `Command-R` |

- `Command-N`（新建任务）、`Command-,`（设置）、查找、系统侧边栏命令以及编辑器
  Return/Escape 继续遵循 macOS 标准，不进入录制器。
- 删除、停止全部计时、数据重置等高风险动作不进入全局快捷键；列表行操作和分析周期
  等局部交互继续使用原生键盘导航。
- 新增上下文动作的默认值为 `nil`，但菜单始终可发现，设置中可自行录制；不可用时菜单
  置灰而非隐藏。
