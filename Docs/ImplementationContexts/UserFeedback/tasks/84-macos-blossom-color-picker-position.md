## 认领的反馈条目

- macOS 上 Blossom Color Picker 应从用户触发它的颜色控件附近出现。
- 不应漂移到窗口角落、无关视图或屏幕上的意外位置。

## 初始范围

- 审计所有 BlossomColorPicker 调用点、macOS 展示容器、popover 锚点与窗口坐标行为。
- 对照项目当前锁定版本的官方源码与公开 API，优先修正调用契约。
- 保持 iPhone/iPad 现有颜色选择交互不变，不改变颜色持久化语义。

## UI 验收清单（改动前）

- [ ] macOS 普通窗口尺寸下，picker 紧邻触发它的颜色控件出现。
- [ ] 窗口移动或调整尺寸后再次打开，picker 仍锚定正确。
- [ ] picker 不遮挡当前触发控件的主要内容，关闭/重开行为稳定。
- [ ] iPhone/iPad 原有颜色选择路径无回退。
- [ ] macOS 正常字号自动化断言与截图覆盖错误位置的回归。

## 测试优先清单

- [ ] 先复现并补 macOS UI 自动化红测。
- [ ] 实现后跑受影响定向测试、完整 `make test`、格式与本地化门禁。
- [ ] macOS 截图验收并清理自有资源。
- [ ] `make build-install-all` 安装最终任务版本。

## 库策略

- 继续使用项目已有的 BlossomColorPicker 固定 revision `9a1ee3d`，先核对其官方源码、
  维护状态和 macOS 展示契约。
- 若上游不提供可靠锚定能力，优先在应用侧做最薄的适配，不复制完整 picker，也不新增
  功能重叠依赖。
